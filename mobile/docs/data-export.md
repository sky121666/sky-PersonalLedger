# 账本文件保存

副本和交易明细下载完成后，客户端打开系统保存入口，由用户选择保存位置。iOS/Android 向 file_picker 的原生保存接口传入下载字节，系统文档提供方负责写入；桌面端先选择路径，再写入相同字节。当前锁定 file_picker 8.3.7，未新增或升级依赖。

Flutter Web 使用现有 `PlatformFile.xFile.saveTo` 浏览器适配，把下载字节放入本地 Blob，并通过浏览器下载入口发送请求。文件名从响应头解码后剥除路径片段，直接设置下载名称，避免 `%`、空格或中文被再次 URL 解码。反馈为“下载请求已发送，请在浏览器中确认保存”，不声称最终落盘；浏览器后续取消或拦截不提供可靠回执。

取消系统保存只显示“已取消保存”，不显示已保存文件名。空下载内容、选择器异常或桌面写入失败会报告失败；客户端不自动分享、上传或发送账本文件。系统选择器可显示用户配置的文件提供方，具体位置由用户决定。

macOS DebugProfile 和 Release 使用 `com.apple.security.files.user-selected.read-write`，以允许写入用户在系统对话框中选择的文件。保留应用沙箱，不申请全盘访问。已签名安装包需要用更新后的 entitlement 正常重新构建及签名，本次 Dart 合成测试不能代替真实签名安装包的系统保存验收。

恢复完成回调在发起请求前捕获，并绑定当时的会话和账本数据代次。用户在请求未结束时返回首页，成功响应仍会刷新账本；退出登录或另一次恢复已完成后，旧回调失效，不能再次刷新或恢复旧状态。回调不依赖已销毁页面的 WidgetRef。

恢复成功会增加账本数据代次，替换所有业务仓库与缓存，并重建路由内保活页面，返回首页。认证令牌和已认证状态继续保留；恢复成功通知仍可见。桌面/移动设备的系统文件提供方、权限拒绝与取消需在目标安装包上最终确认。
