# 功能需求规格说明

## 1. 用户认证

### 1.1 初始化设置

- **触发条件**: 首次启动 App 或本地无用户数据
- **功能描述**: 用户设置登录密码，完成初始化
- **输入**: 密码 (6-20位，至少包含数字和字母)
- **输出**: 创建用户记录，生成 Token，跳转首页
- **验收标准**:
  - [ ] 密码强度校验
  - [ ] 确认密码一致性校验
  - [ ] 初始化成功后自动登录

### 1.2 登录

- **触发条件**: Token 过期或用户主动退出后重新进入
- **功能描述**: 用户输入密码登录
- **输入**: 密码
- **输出**: 验证成功返回 Token，跳转首页
- **验收标准**:
  - [ ] 连续 5 次失败锁定 15 分钟
  - [ ] 支持生物识别 (指纹/Face ID) 快捷登录
  - [ ] 记住登录状态 30 天

### 1.3 修改密码

- **入口**: 设置页 > 安全设置 > 修改密码
- **输入**: 原密码、新密码、确认新密码
- **验收标准**:
  - [ ] 原密码验证正确
  - [ ] 新密码符合强度要求
  - [ ] 修改成功后清除所有 Token，重新登录

## 2. 账户管理

### 2.1 账户类型

| 类型 | 标识 | 余额方向 | 说明 |
|------|------|----------|------|
| 现金 | `cash` | 正向 | 手头现金 |
| 银行卡 | `bank_card` | 正向 | 储蓄卡、借记卡 |
| 支付宝 | `alipay` | 正向 | 支付宝余额 |
| 微信 | `wechat` | 正向 | 微信零钱 |
| 信用卡 | `credit` | 负向 | 欠款为正，还款后归零 |
| 贷款 | `loan` | 负向 | 房贷、车贷等 |
| 应收款 | `receivable` | 正向 | 借出的钱 |
| 应付款 | `payable` | 负向 | 借入的钱 |

### 2.2 创建账户

- **入口**: 账户页 > 右上角 "+" 按钮
- **必填字段**: 账户名称、账户类型、初始余额
- **可选字段**: 图标、还款日 (信用卡/贷款)、备注
- **验收标准**:
  - [ ] 账户名称不可重复
  - [ ] 初始余额允许负数 (信用卡/贷款)
  - [ ] 创建成功后刷新账户列表

### 2.3 编辑账户

- **入口**: 账户详情页 > 编辑按钮
- **可编辑字段**: 名称、图标、还款日、备注
- **不可编辑**: 账户类型、初始余额
- **验收标准**:
  - [ ] 余额由交易自动计算，不可手动修改

### 2.4 删除/归档账户

- **删除**: 仅允许删除余额为 0 且无交易记录的账户
- **归档**: 隐藏账户，不计入总资产，保留历史记录
- **验收标准**:
  - [ ] 删除前二次确认
  - [ ] 归档账户可在设置中恢复

### 2.5 账户排序

- **方式**: 拖拽排序
- **验收标准**:
  - [ ] 排序结果持久化
  - [ ] PC 端支持拖拽，移动端支持长按拖拽

## 3. 交易记录

### 3.1 交易类型

| 类型 | 标识 | 余额影响 |
|------|------|----------|
| 支出 | `expense` | 账户余额减少 |
| 收入 | `income` | 账户余额增加 |
| 转账 | `transfer` | 源账户减少，目标账户增加 |

### 3.2 新增交易

- **入口**: 底部 Tab "+" 按钮 (移动端) / 侧边栏快捷入口 (PC)
- **必填字段**: 金额、交易类型、账户、日期
- **可选字段**: 分类、备注、标签、图片
- **验收标准**:
  - [ ] 金额必须大于 0
  - [ ] 转账必须选择不同的源/目标账户
  - [ ] 保存后立即更新账户余额
  - [ ] 支持保存为快捷模板

### 3.3 编辑交易

- **入口**: 交易详情页 > 编辑按钮
- **可编辑字段**: 全部字段
- **验收标准**:
  - [ ] 编辑后自动重算相关账户余额
  - [ ] 不可修改交易类型 (需删除重建)

### 3.4 删除交易

- **验收标准**:
  - [ ] 删除前二次确认
  - [ ] 删除后自动回滚账户余额
  - [ ] 支持批量删除

### 3.5 交易列表

- **默认排序**: 按交易日期倒序
- **筛选条件**: 时间范围、账户、分类、类型、金额范围
- **分组方式**: 按日期分组显示
- **验收标准**:
  - [ ] 支持下拉刷新、上拉加载更多
  - [ ] 显示每日小计 (收入/支出)

### 3.6 快捷记账模板

- **功能**: 保存常用交易为模板，一键记账
- **模板内容**: 金额、账户、分类、备注
- **验收标准**:
  - [ ] 首页显示最近使用的模板
  - [ ] 支持编辑/删除模板

## 4. 分类管理

### 4.1 分类结构

- **层级**: 一级分类 (不支持多级)
- **类型**: 收入分类、支出分类 (分开管理)
- **系统预设**: 提供默认分类，用户可修改/删除

### 4.2 默认支出分类

餐饮、交通、购物、娱乐、居住、医疗、教育、通讯、服饰、美容、运动、旅行、社交、宠物、其他

### 4.3 默认收入分类

工资、奖金、理财、兼职、报销、红包、其他

### 4.4 自定义分类

- **入口**: 设置 > 分类管理
- **可设置**: 名称、图标、颜色、排序
- **验收标准**:
  - [ ] 分类名称不可重复
  - [ ] 删除分类时，已使用该分类的交易保留，显示"未分类"

---

## 5. 预算管理

### 5.1 预算类型

| 类型 | 说明 |
|------|------|
| 总预算 | 当月总支出上限 |
| 分类预算 | 单个分类的支出上限 |

### 5.2 设置预算

- **入口**: 预算页 > 设置预算
- **周期**: 月度 (每月 1 日重置)
- **字段**: 预算金额、预警阈值 (默认 80%)
- **验收标准**:
  - [ ] 分类预算之和可超过总预算 (仅预警)
  - [ ] 预算金额必须大于 0

### 5.3 预算展示

- **首页卡片**: 显示当月预算使用进度
- **预算详情页**: 
  - 总预算进度条
  - 各分类预算进度条
  - 超支分类红色高亮
- **验收标准**:
  - [ ] 达到预警阈值时首页卡片变色提示
  - [ ] 超支时显示超支金额

---

## 6. 还款提醒

### 6.1 创建提醒

- **关联对象**: 信用卡或贷款类型账户
- **字段**: 还款日 (1-31)、提前提醒天数、还款金额 (可选)
- **验收标准**:
  - [ ] 每个账户只能创建一个提醒
  - [ ] 还款日若当月无此日 (如 31 日)，自动调整为月末

### 6.2 提醒方式

| 渠道 | 说明 |
|------|------|
| App 推送 | 本地通知 |
| 系统日历 | 写入系统日历事件 |

### 6.3 提醒触发

- **触发时机**: 还款日前 N 天的早上 9:00
- **验收标准**:
  - [ ] 点击通知跳转到对应账户详情
  - [ ] 提醒后不重复提醒 (同一周期)

## 7. 数据统计

### 7.1 月度概览

- **入口**: 统计页 (Tab)
- **内容**:
  - 本月总收入、总支出、结余
  - 与上月对比 (涨跌百分比)
  - 日均支出
- **验收标准**:
  - [ ] 支持切换月份查看历史数据

### 7.2 分类占比

- **图表**: 环形图 (Donut Chart)
- **数据**: 各分类支出金额及占比
- **交互**: 点击扇区显示详情
- **验收标准**:
  - [ ] 支持切换收入/支出视图
  - [ ] 占比小于 3% 的分类合并为"其他"

### 7.3 趋势图

- **图表**: 柱状图 / 折线图
- **维度**: 按日 / 按周 / 按月
- **验收标准**:
  - [ ] 支持切换时间维度
  - [ ] 显示收入/支出对比

### 7.4 分类排行

- **展示**: 进度条形式
- **排序**: 按金额降序
- **验收标准**:
  - [ ] 点击分类可查看该分类下所有交易

## 8. 账单导入

### 8.1 支持格式

| 来源 | 格式 | 说明 |
|------|------|------|
| 微信 | CSV | 微信支付账单导出 |
| 支付宝 | CSV | 支付宝账单导出 |
| 银行 | CSV | 各银行账单格式 (需适配) |

### 8.2 导入流程

1. 用户选择账单文件
2. 系统解析账单，预览导入数据
3. 用户选择目标账户、确认分类映射
4. 执行导入，显示结果

### 8.3 验收标准

- [ ] 支持增量导入 (跳过已存在记录)
- [ ] 自动识别交易类型 (收入/支出)
- [ ] 支持自定义分类映射规则
- [ ] 导入失败的记录单独标记

---

## 9. 数据管理

### 9.1 数据导出

- **格式**: CSV / JSON
- **范围**: 全部 / 按时间范围
- **验收标准**:
  - [ ] 导出文件包含所有交易字段
  - [ ] 支持分享到其他 App

### 9.2 数据备份

- **方式**: 导出 SQLite 数据库文件
- **验收标准**:
  - [ ] 备份文件可导入恢复
  - [ ] 支持定期自动备份 (可选)

### 9.3 数据清除

- **选项**: 清除所有数据 / 仅清除交易记录
- **验收标准**:
  - [ ] 需输入密码确认
  - [ ] 清除后无法恢复
