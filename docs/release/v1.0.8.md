# Personal Ledger v1.0.8

## 发布范围

v1.0.8 的正式发布范围是 Docker/Web。Android 和 iOS 只提供开发构建、模拟器运行验证和截图证据，不要求商店签名。

## 变更

- Web 增加真实后端 Playwright E2E，覆盖登录、错误密码、交易新增/编辑/删除和移动视口主导航。
- Web 增加生产构建体积预算和依赖漏洞门禁。
- 后端补充备份 API 演练、外部集成契约、运行健康和性能检查。
- 移动端 premium smoke 改为严格控件契约，并修正宽屏快速记账入口和多尺寸截图安全区。
- Dependabot 每个生态最多保留一个更新候选。
- README、功能文档、开发部署和截图证据拆分到 docs/。

- Android USB 真机 debug 安装受设备策略限制，本版本使用 API 35 模拟器证据。
- iOS 使用 iPhone 17 Simulator，不等同于实体 iPhone。
- 本版本不提供正式签名 APK/AAB/IPA。
