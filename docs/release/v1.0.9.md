# Personal Ledger v1.0.9

## 发布范围

v1.0.9 的正式发布主路径是 Docker/Web：

- `ghcr.io/sky121666/sky-personalledger:1.0.9`；
- `linux/amd64` 与 `linux/arm64`；
- digest 固定的 `docker-compose-v1.0.9.yml`；
- `docker-compose-v1.0.9.yml.sha256`。

Android 与 iOS 作为同一源码的开发客户端，已完成模拟器真实后端 E2E 和运行截图；本次
不发布签名 APK、AAB、IPA 或 TestFlight，也不把模拟器结果描述为实体 iPhone 或商店验收。

## 主要变化

### 数据一致性与附件

- 交易、提醒、借贷、通知与附件写操作只在服务端确认成功后刷新客户端状态。
- Flutter 附件采用分阶段同步；核心交易成功但附件失败时返回可识别的部分成功状态，支持安全重试。
- 恢复流程增加附件维护屏障、暂存激活、路径与引用校验、大小限制、完整性证据和失败恢复。
- 备份格式保持 2.3，继续排除密码、刷新令牌、API Token、AI Provider 和通知凭据。

### 凭据与服务安全

- 增加独立 `LEDGER_CREDENTIAL_ENCRYPTION_KEY`，把 AI/通知凭据生命周期与 JWT 轮换分离。
- 启动时对受支持的历史凭据执行事务性迁移，失败时不会静默丢失旧值。
- 加固首次初始化、JSON 请求体上限、可信代理、CORS、错误响应、健康检查和私网出站策略。
- release 模式默认仅绑定回环地址、拒绝通配 CORS，并阻止用户配置的外部集成访问私网。

### Web 与 Flutter

- Web 增加请求世代保护，避免较旧响应覆盖新状态，并改善响应式导航、设置与操作反馈。
- Flutter 加固服务器地址验证、本地安全状态、认证刷新、快速记账、提醒、借贷和跨页面刷新。
- Web 真实后端 Playwright 覆盖登录、错误密码、交易新增/编辑/删除、移动视口导航和快速记账。
- Flutter 真实后端 E2E 覆盖 flutter-tester、Android API 35 模拟器和 iOS Simulator。

### 发布链

- 版本 tag 必须属于受保护的 `main`，Release 和 GHCR 版本均禁止复用。
- Docker 从一个多架构 OCI layout 生成 amd64/arm64 扫描输入；两架构扫描通过后才登录 GHCR。
- 扫描后的 OCI 归档按校验和与 OCI digest 封存，发布 job 只推送同一份 layout，不重新构建。
- 新增 Docker/Web 范围化 source gate 与发布后 manifest/runtime gate，移动签名不再阻断 Docker/Web。
- GitHub Release 自动生成 digest 固定的 Compose 和 SHA-256 附件，不创建或移动 `latest`。

## 验证摘要

发布候选在 2026-08-24 完成以下本地验证：

- Go 全量测试、race 测试、关键恢复/附件/凭据/通知测试 10 轮和 `go vet`；
- Web 60 个单元测试、生产构建、bundle/附件门禁、2 个真实后端 Playwright 流程；
- Flutter analyzer、404 个通过测试与 1 个设计性 skip、48 个明暗模式屏幕用例；
- flutter-tester、Android 模拟器、iOS Simulator 真实后端 E2E；
- 备份恢复、凭据迁移、AI 隐私、健康、外部集成和公共仓库安全合同；
- 当前源码 Docker image/Compose 的健康、持久化、非 root、指标鉴权和配置保护；
- `LOCAL_FINAL_RELEASE=1 ./scripts/check-final-release-gates.sh`。

tag 推送后的工作流继续强制 Web、后端、安全、双架构扫描、GHCR manifest 和发布镜像

## 安装与升级

首次安装使用 README 的 [Docker 快速部署](../../README.md#docker-快速部署)。已有部署升级前：

1. 备份 `data/` 与受限的本机 `.env`；
2. 记录现有镜像 digest，保留可回滚版本；
3. 设置并保留稳定的 `LEDGER_CREDENTIAL_ENCRYPTION_KEY`；
4. 下载 Release 的 v1.0.9 Compose 和 `.sha256`，校验后再部署；
5. 验证健康、登录、交易、附件、通知、家庭数据与 AI 报告；
6. 确认迁移和备份可用前，不删除旧密钥、旧镜像或升级前备份。

完整步骤见 [部署与配置](../development/deployment.md)。

## 已知限制

- 不提供正式签名 APK、AAB、IPA 或 TestFlight 构建。
- iOS 证据来自 Simulator，不等同于实体 iPhone；未声明 VoiceOver/TalkBack 手工验收。
- 附件维护屏障是进程内机制；共享同一上传目录仅支持一个可写应用实例。
- 仓库当前没有 `LICENSE` 文件，源码公开可见但许可边界尚未声明。
