# 首页小组件交互修正与验收

日期：2026-10-20。交付状态：实现、独立审查整改、最终受影响回归及现有 Demo 实际操作完成。

## 设计边界

参考 `theme-sky-blog-3` 的小组件编辑、组件中心和按需菜单交互，沿用当前 Vue、图标、偏好草稿与财务读模型。

保留原卡片外观：13 个渲染组件文件与修正前哈希一致，`workspace.css` 中导航注释之前的卡片基础样式原文一致。没有修改财务口径、API、后端、认证、schema、依赖、CI 或 Docker。

本轮不复制博客的 Dock、桌面图标、壁纸或窗口管理系统。主题仓库仅作只读参考。

## 已修正的问题

| 问题 | 最终行为 |
| --- | --- |
| 首页重复品牌页头与常驻操作条占用内容空间 | 侧栏与全局顶部导航仍互斥；首页移除重复 Logo 横幅，标题、月份及编辑/隐私/刷新集中在一行 |
| 编辑时标题、尺寸、排序堆在每张卡片上方 | 保留卡片原尺寸；角标移除、居中手柄、按需选项菜单，不再挤高卡片 |
| 拖动只有变暗与描边，反馈不足 | fixed 浮层跟随指针，原位保留轮廓，目标描边；松手后按真实顺序让位 |
| 拖动浮层扩大滚动内容范围 | 浮层放在 body 下，使用 DOM snapshot，避免重挂载读取数据的 Vue 组件；取消和卸载统一清理 |
| 动画中抓取发生跳位、近乎静止松手误排序 | 抓取时暂停正在进行的 FLIP，保持屏幕几何；恢复时继续动画；提交排序要求至少 6px 位移 |
| 画廊搜索后右侧仍显示无关组件 | 筛选与选中项联动；零匹配没有旧组件添加入口 |
| 手机画廊选中项被横向目录截住 | 挂载、筛选和选中变化后居中当前项；两端保留已添加标识 |
| 深色浮层和角标样式失效 | 修正 scoped CSS 的祖先主题选择器，避免规则退化成文档根 `.dark` 样式 |
| 长页面账户菜单被滚动提前关闭 | 使用实际滚动容器、编辑栏与手机导航的可见边界重定位；离屏关闭时恢复触发器焦点 |
| 手机“更多”操作越界 | 相对整个编辑栏定位，宽度限制在编辑栏内 |
| 画廊卸载回焦覆盖“定位已有组件” | 回焦统一由 HomeView 管理；定位后滚动到目标，聚焦拖动手柄 |
| 画廊关闭动画期间仍可通过键盘添加 | closing 时内容 inert、按钮 disabled，提交处理同步再次检查 |

动效采用现有浏览器能力，没有新增运行时依赖：卡片让位为 260ms、侧栏宽度为 240ms、菜单为 100–140ms、画廊进出为 140–220ms。系统减少动态效果时跳过这些过渡；拖动仍跟随真实指针，不使用自动抖动。
