# 小组件设计结构参考

这些图片来自本次已讨论的 macOS 小组件方向，仅用于组件轮廓、网格、画廊和导航关系。它们是生成式静态概念，不是运行中的业务页面。

最终实现以 [开发规格](../../superpowers/specs/2026-10-19-web-widgets-design.md) 为准。用户在选定方案后明确要求纯色背景，图片里的蓝色背景曲线、壁纸和页面渐变均不实现。

| 参考 | 用途 |

必须覆盖生成图细节的规则：

- 页面浅色 `#F2F2F7`、深色 `#0B0B0D`；蓝色只作强调，玻璃主要用于导航和浮层。
- 不重复品牌图标，不复制 OS 菜单栏、Dock、系统桌面或浏览器外壳。
- 还款汇总没有下一笔金额字段；不把图中的 `600.00` 写成真实业务规则。
- 还款范围仍是提醒，不含账户分期。实际到期日期不能仅凭图中的 `22` 推导。
- 转账金额为中性色；不按生成图重新定义借贷、还款或资产统计。
- 不做无依据的收支占比堆叠，不伪造账户/净资产历史曲线。
- 财务大数字与长名称优先可读，不能照图片固定缩小字号或截断。
- 五张图不代表拖动、保存、键盘、触控或安全区已经验收。

参考文件只放在文档目录，不引入运行时 bundle，不作为页面背景或组件图片加载。
