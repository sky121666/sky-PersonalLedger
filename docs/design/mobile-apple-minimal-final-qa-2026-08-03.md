# 移动端 Apple 简约风最终 QA

## 结论

当前移动端核心路径达到可接受的 Apple 简约风基线：层级清楚、留白克制、颜色语义稳定，主要操作保持 44pt 级触控目标。未发现阻断使用的 P0/P1 视觉问题。

本结论只覆盖下列本轮证据，不把历史截图或自动化断言冒充实机视觉证据。原生 Android/iOS 真实后端 E2E 已分别通过发布门禁。

## 逐步审查

1. 首页 — 健康：核心余额是第一视觉焦点，信息密度适中，底栏不遮挡内容。
2. 明细 — 健康：搜索与筛选入口明确，收入/支出颜色和正负号一致。
3. 统计 — 健康：汇总、周期和图表顺序自然，图表标签可读。
4. 功能 — 健康：采用 iOS 设置式分组表面，入口名称可独立理解。
5. 快速记账 — 健康：底部面板与背景层级明确，主按钮突出，表单路径完整。
6. 数据管理 — 健康：副本、明细、导入、恢复和自动保存按风险与频率分组。
7. 设备授权 — 健康：设备、有效期、最小权限标签与删除操作同时可见。

## 设计判断

- 保留 `当月 / 今年 / 往年` 分段选择器。它比单月份下拉更符合现有真实产品能力，属于已接受的 P3 产品差异。
- 功能页底部出现下一行的部分内容，是可滚动列表的继续提示；实际元素可滚动到完整位置，不属于遮挡缺陷。
- 不引入装饰性插画、渐变堆叠或额外品牌色，以保持财务工具的安静和可信感。

## 可访问性与证据边界

- 本轮可访问性树确认底栏、快速记账表单和主要操作均有可识别语义。
- 自动化回归覆盖触控目标、语义标签及稳定渲染。
- 未执行 VoiceOver 人工朗读顺序、动态字体最大档或真机户外对比度测试；这些属于后续发布签核证据，不能由截图推断。

## 剩余发布签核项

- 发布候选版本仍需真机 VoiceOver、最大动态字体和弱网恢复检查。
