# 记账与账本

## 交易

支持收入、支出和转账。交易可以绑定账户、分类、家庭成员、标签、日期、备注和附件。

Web 页面提供：

- 快速记账和编辑交易；
- 按日期、类型、分类和关键词筛选；
- 单条或批量删除；
- 交易明细和附件管理。

移动端提供原生快速记账表单，并通过 API Client 直连服务端。

## 账户与分类

账户支持现金、银行卡、支付宝、微信等类型，也支持归档、排序、初始余额和负债属性。账户余额由交易变更逻辑统一维护，并记录账户日志。

分类分为收入和支出两类。系统初始化时会创建默认分类，用户可以继续创建、编辑和删除自定义分类。

## 标签与模板

标签用于给交易增加可筛选的业务标记。快捷模板保存常用交易参数，并可直接套用生成交易。

## 预算、提醒与借贷

- 总预算、分类预算和预算摘要；
- 付款提醒和提醒状态切换；
- 借出、借入、还款记录及借贷汇总；
- 借贷相关提醒会进入债务摘要。

## 导入、导出与报表

交易导入采用预览、校验、提交、回滚四步，避免未经确认的数据直接写入。

导出能力包括：

- 交易 CSV；
- 可用年份列表；
- 年度汇总和趋势报表。

相关后端路由位于：

- /transactions
- /imports/transactions
- /export/transactions/csv
- /export/report/yearly
- /budgets
- /reminders
- /lendings
