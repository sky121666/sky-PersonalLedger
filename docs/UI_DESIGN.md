# UI/UX 设计规范 - Sky Personal Ledger

## 1. 设计理念

遵循 Apple Human Interface Guidelines (HIG)。核心关键词：**简约、清晰、流畅**。

- **清晰 (Clarity)**: 文本易读，图标精确，装饰适度，以内容为中心。去除不必要的分割线和装饰元素。
- **顺从 (Deference)**: UI 界面应辅助内容，利用模糊和半透明效果 (Blur/Translucency) 提示层级。
- **深度 (Depth)**: 通过细腻的阴影和层级关系构建空间感。

## 2. 颜色系统 (Color System)

采用 iOS 系统级配色方案，支持深色模式 (Dark Mode)。

### 背景色 (Backgrounds)

| 用途 | Light Mode | Dark Mode | 说明 |
|------|------------|-----------|------|
| **主背景** | `#F2F2F7` | `#000000` | 页面底层 (System Grouped Background) |
| **卡片/内容** | `#FFFFFF` | `#1C1C1E` | 内容承载容器 (Secondary System Grouped Background) |
| **浮层/模态** | `#FFFFFF` | `#2C2C2E` | 弹窗、ActionSheet |

### 功能色 (Functional Colors)

| 用途 | 色值 (Hex) | 说明 |
|------|------------|------|
| **Primary** | `#007AFF` | 系统蓝，用于按钮、选中状态、链接 |
| **Income** | `#34C759` | 系统绿，用于收入金额、正向趋势 |
| **Expense** | `#FF3B30` | 系统红，用于支出金额、负向趋势、错误 |
| **Warning** | `#FF9500` | 系统橙，用于提醒、待办 |
| **Text Primary** | `#000000` / `#FFFFFF` | 主要文字 |
| **Text Secondary** | `#8E8E93` | 次要文字、说明、日期 |
| **Separator** | `#C6C6C8` / `#38383A` | 分割线 (透明度 30%) |

## 3. 排版 (Typography)

使用系统默认字体 (San Francisco on iOS, Roboto on Android)。

- **Large Title**: `34pt` (Bold) - 页面一级标题
- **Title 2**: `22pt` (Semibold) - 卡片/模块标题
- **Headline**: `17pt` (Semibold) - 列表项主要信息
- **Body**: `17pt` (Regular) - 正文
- **Subhead**: `15pt` (Regular) - 次要信息
- **Caption 1**: `12pt` (Regular) - 辅助说明、日期标签

> **注意**: 涉及金额显示的数字，必须使用**等宽数字 (Monospaced Digits)** 设置，以确保列表中的金额对齐。

## 4. 图标系统 (Iconography)

统一使用类 **SF Symbols** 风格的线性图标。

- **风格**: 线性 (Outline) 为主，选中状态使用填充 (Filled)。
- **线宽**: Medium 或 Semibold，保持视觉统一。
- **尺寸**:
  - 导航栏图标: `24x24pt`
  - 列表左侧图标: `20x20pt` 或 `24x24pt`
  - 分类大图标: `32x32pt`

**底部导航栏 (Tab Bar)**:

1. **首页**: House / Grid
2. **明细**: List.Bullet.Rectangle
3. **统计**: Chart.Pie
4. **我的**: Person.Circle

## 5. 布局与组件 (Components)

### 卡片 (Cards)

- **圆角**: `12px` (小卡片) 或 `16px` (大模块)。
- **样式**: `Inset Grouped` 风格，即页面左右留白 `16px`，卡片充满中间区域。
- **阴影**: 极淡的弥散阴影 `0 2px 8px rgba(0,0,0,0.04)` (仅在 Light Mode 下需要，Dark Mode 靠亮度区分)。

### 列表 (Lists)

- **高度**: 单行标准高度 `44px` 或 `50px`。
- **分割线**: 左侧对齐文字缩进 (padding-left: 16px)，右侧通栏。
- **操作**: 支持左滑出现操作菜单 (删除-红色，编辑-蓝色)。

### 按钮 (Buttons)

- **主按钮**: 高度 `44px` - `50px`，圆角 `8px` 或 `12px`，蓝色背景白字。
- **悬浮按钮 (FAB)**: 仅在必要时使用，通常推荐将主要操作放在导航栏右上角或页面显眼位置。
- **键盘**: 记账页使用自定义数字键盘，贴合底部。

## 6. 关键页面视觉规范

### 6.1 首页 (Dashboard)

- **顶部区域**:
  - 沉浸式状态栏。
  - "总资产" 卡片采用微渐变背景 (如深蓝渐变)，文字白色。
- **数据展示**:
  - 关键数字字号加大 (`28pt`+)。
  - 隐藏具体金额的 "眼睛" 按钮。

### 6.2 记账页 (Transaction)

- **核心体验**: 快速。
- **布局**: 上半部分显示金额输入 (超大字号)，下半部分为分类网格 + 数字键盘。
- **分类**:
  - `4-5` 列网格布局。
  - 选中时图标变色并有浅色背景圆圈。

### 6.3 统计页 (Statistics)

- **图表**:
  - 环形图 (Donut Chart) 中心显示总支出。
  - 柱状图 (Bar Chart) 显示每日/月趋势。
  - 颜色取自功能色板，降低饱和度以适应大面积显示。
- **排行榜**: 进度条形式，左侧分类名，右侧金额和百分比。

## 7. 交互动效 (Interaction)

- **转场**: iOS 原生 Push/Pop 动画。
- **弹窗**: 优先使用 **Sheet** (底部半屏弹窗) 而非 Alert (中间弹窗)，方便单手操作。
- **反馈**: 按钮点击要有缩放或透明度变化的反馈 (Active State)。

## 8. 多端适配策略 (Responsive Design)

本项目**全端统一采用 Apple 极简主义设计风格**，通过响应式布局适配不同屏幕尺寸。

### 8.1 平台区分

| 平台 | 设计风格 | 布局模式 |
|------|----------|----------|
| **Android / iOS App** | Apple 极简风 | 单栏全屏 + 底部导航 |
| **微信小程序** | Apple 极简风 | 单栏全屏 + 底部导航 |
| **H5 移动端** (< 768px) | Apple 极简风 | 单栏全屏 + 底部导航 (与 App 一致) |
| **H5 PC 端** (≥ 768px) | Apple 极简风 | 侧边栏导航 + 多列卡片布局 |

### 8.3 PC 端设计特点 (保持 Apple 简约风)

| 元素 | 移动端 | PC 端 |
|------|--------|-------|
| **设计风格** | Apple 极简风 | Apple 极简风 (同移动端) |
| **导航** | 底部 Tab Bar | 左侧简约侧边栏 (200-240px) |
| **内容区宽度** | 100% | 最大 1200px，居中 |
| **卡片布局** | 单列堆叠 | 多列网格 (2-3 列)，保持圆角卡片风格 |
| **表单输入** | 数字键盘 + 全屏 | 模态弹窗，保持移动端样式 |
| **列表** | 卡片化列表 | 卡片化列表 (可切换表格视图) |
| **交互** | 触控手势 | 悬停高亮、点击反馈 |
| **视觉一致性** | - | 与移动端共享配色、圆角、阴影、图标 |

### 8.4 响应式断点

```scss
// 断点定义
$breakpoint-mobile: 768px;
$breakpoint-tablet: 1024px;
$breakpoint-desktop: 1200px;

// 使用示例
.sidebar {
  display: none;  // 移动端隐藏
  
  @media (min-width: $breakpoint-mobile) {
    display: block;
    width: 200px;
  }
}

.main-content {
  width: 100%;
  
  @media (min-width: $breakpoint-mobile) {
    margin-left: 200px;
    width: calc(100% - 200px);
  }
}
```

### 8.6 PC 端增强组件 (Apple 风格)

| 组件 | 说明 |
|------|------|
| **侧边栏导航** | 简约风格，图标 + 文字，可折叠为纯图标模式 |
| **多列卡片** | 首页/统计页采用 2-3 列卡片网格布局 |
| **悬浮操作** | 鼠标悬停显示操作按钮（保持简约，不用右键菜单） |
| **快捷键** | 支持键盘快捷操作 (Ctrl+N 新建等) |
| **拖拽排序** | 账户/分类支持拖拽调整顺序 |

### 8.7 设计一致性原则

> **核心原则**: PC 端是移动端的"放大版"，而非完全不同的设计。

- **共享设计系统**: 配色、字体、圆角、阴影、图标全端一致
- **组件复用**: 卡片、按钮、输入框等基础组件样式统一
- **仅调整布局**: PC 端只是将单列变多列，底部导航变侧边栏
- **保持简约**: 避免 PC 端"功能膨胀"，保持移动端的精简体验
